# ChatApp Backend

## Run
1. Copy `.env.example` to `.env`.
2. Set `MONGO_URI` and `JWT_SECRET`.
3. Run:
   npm install
   npm start

Server: http://localhost:3000

## Tests
Run the backend unit tests with:

```bash
npm test
```

## Main concepts
- Express server
- REST APIs
- bcrypt password hashing
- JWT authentication
- MongoDB/Mongoose
- Socket.IO
- Socket authentication
- Personal rooms
- Unique room IDs
- Real-time messages
